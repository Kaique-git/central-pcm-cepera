Pasta OneDrive: Não vinculada neste navegador

Agora qualquer usuário pode simplesmente arrastar e soltar PDFs, Fotos ou Planilhas direto no sistema (sem copiar link do SharePoint!). Se você vincular abaixo a sua pasta já sincronizada no OneDrive (PCM CEPERA - Levantamento Manutenção Preventiva - Documentos), tudo que você arrastar no sistema também será salvo e renomeado automaticamente dentro da pasta correta do SharePoint!

🤖 Não consegue sincronizar o OneDrive no PC? Use o Webhook Power Automate (100% Nuvem)

Se o OneDrive Desktop estiver bloqueado na sua máquina, os documentos até 7 MB já funcionam normalmente salvos no banco do sistema. Se desejar que cada arquivo enviado/aprovado também seja gravado automaticamente dentro das pastas do SharePoint pela nuvem:

  1. No Power Automate, crie um fluxo Instantâneo com gatilho "Quando uma solicitação HTTP for recebida" (JSON com campos pastaRelativa, nomeArquivo, conteudoBase64, mimeType).
  2. Adicione a ação SharePoint → Criar arquivo apontando para este site, pasta Documentos Compartilhados/@{triggerBody()?['pastaRelativa']}, nome @{triggerBody()?['nomeArquivo']} e conteúdo @{base64ToBinary(triggerBody()?['conteudoBase64'])}.
  3. Adicione uma ação Resposta HTTP (200) devolvendo {"arquivoUrl": "https://ceperaind.sharepoint.com..."} e cole a URL do gatilho no campo Webhook Power Automate abaixo.
⚠️ Ajuda rápida para sincronização inicial de pastas no SharePoint / OneDrive
⚡ Criar árvore via Web Console (F12):

1. Clique em "⚡ Copiar Script Console Web" acima.
2. No SharePoint, aperte F12 > Console, cole (Ctrl+V) e dê Enter.

🔄 Destravar erro "Você já está sincronizando um atalho":

Abra seu OneDrive, clique com botão direito na pasta com ícone de correntinha azul e escolha "Remover atalho". Depois clique em Sincronizar no SharePoint.
