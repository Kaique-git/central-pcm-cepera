Ponte Nuvem SharePoint via Power Automate

Quando você copiar os manuais do J: para o SharePoint, conecte o fluxo abaixo para qualquer PC consultar os PDFs na nuvem automaticamente.

⚡ Passo a passo para montar o fluxo de busca no Power Automate (2 minutos)
  1. Gatilho: Quando uma solicitação HTTP for recebida → cole o esquema JSON copiado no botão acima (campos ativo, tokens, pastaBase).
  2. Ação 1: SharePoint → Obter arquivos (somente propriedades) na biblioteca onde subiu a pasta J:, filtrando nomes que contenham o primeiro termo de tokens.
  3. Ação 2 (para até 3 PDFs encontrados): SharePoint → Obter conteúdo do arquivo e monte um array arquivos com {"nome", "caminho", "mimeType": "application/pdf", "conteudoBase64"}.
  4. Ação 3: Resposta HTTP (200) devolvendo {"arquivos": [...]}. Cole a URL gerada acima e clique em Salvar Ponte.
